# WPF XAML Live Preview v0.1.0 (미리보기 릴리스)

VS Code에서 `.xaml` 파일을 편집하면서 **실제 WPF 렌더링 결과**를 옆 패널에서 바로 확인하는 확장입니다.
Visual Studio 없이 **.NET SDK 10**으로 WPF 프로젝트를 개발할 때 쓰는 것을 목표로 합니다. **Windows 전용.**

> **이 버전은 시험 단계(Pre-release)입니다.** 자동 테스트는 통과했지만 아래 "아직 확인되지 않은 것"을 꼭 읽어 주세요.

## 설치
요구 사항: Windows 10/11 x64, **.NET 10 Desktop Runtime**(없으면 확장이 안내합니다), VS Code 1.90 이상. Visual Studio는 필요 없습니다.

1. 아래 **Assets**에서 `wpf-xaml-live-preview-0.1.0.vsix`와 `SHA256SUMS.txt`를 내려받습니다.
2. (권장) 파일이 변조되지 않았는지 확인합니다. 아래 출력이 `SHA256SUMS.txt`의 값과 같아야 합니다.
   ```powershell
   (Get-FileHash .\wpf-xaml-live-preview-0.1.0.vsix -Algorithm SHA256).Hash.ToLower()
   ```
3. 설치합니다.
   ```powershell
   code --install-extension .\wpf-xaml-live-preview-0.1.0.vsix
   ```
   (또는 VS Code 확장 뷰 → `...` → **VSIX에서 설치**)
4. `.xaml` 파일을 열고 명령 팔레트(`Ctrl+Shift+P`) → **WPF XAML: Open Preview**.

> 이 확장은 Marketplace가 아니라 파일로 배포되므로 **자동 업데이트되지 않습니다.** 새 버전은 새 `.vsix`를 받아 다시 설치하세요.

## 주요 기능
- 편집하면 자동으로 다시 그려지는 실제 WPF 렌더링 미리보기, XAML 오류를 줄/열과 함께 Problems 패널에 표시
- 코드 비하인드 없이 실제 프로젝트 XAML 렌더: `x:Class`/이벤트 제거, `d:`/`mc:`, `Window` 루트, 병합 사전, `App.xaml` 리소스
- 사용자 컨트롤: 신뢰한 폴더에서 프로젝트의 빌드된 DLL을 불러와 실제로 렌더(`dotnet build` 필요), 아니면 자리표시자
- 줌/팬/배경 전환/렌더 크기 지정, 요소 클릭 ↔ XAML 줄 이동·강조

자세한 사용법: [doc/User_Guide.md](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/blob/main/doc/User_Guide.md)

## 알아 두세요 (보안/신뢰)
- **코드 서명이 없습니다.** `.vsix`와 번들된 `XamlRenderHost.exe`가 서명되지 않아 Windows SmartScreen이나 백신이 경고할 수 있습니다. 체크섬은 파일이 바뀌지 않았음만 보여 주고 배포자를 증명하지는 않습니다. 의심스러우면 소스에서 직접 빌드할 수 있습니다(저장소 README).
- **사용자 코드를 실행합니다.** 신뢰한 폴더에서는 프로젝트의 빌드된 DLL을 불러와 컨트롤 생성자 같은 코드를 이 PC에서 실행합니다(샌드박스 없음). 신뢰하지 않은 폴더에서는 실행하지 않습니다.
- **텔레메트리/네트워크 전송이 없습니다.** 로그에 XAML 본문을 남기지 않습니다.
- 라이선스: GPL-3.0-only

## 아직 확인되지 않은 것
- **Visual Studio가 없는 깨끗한 PC에서의 설치/첫 실행**은 아직 사람이 확인하지 못했습니다(자동 테스트는 .NET SDK와 VS가 있는 PC에서 수행).
- **미리보기 화면의 마우스 조작**(드래그 이동, Ctrl+휠 줌, 클릭)은 자동 테스트로 검증하지 못했습니다.
- 정적 렌더입니다(코드 비하인드/이벤트/애니메이션 실행 없음). 드래그 앤 드롭 디자이너와 XAML 자동 완성은 제공하지 않습니다.

문제를 발견하면 **Issues**에 환경(OS, .NET 버전)과 증상을 알려 주세요.
