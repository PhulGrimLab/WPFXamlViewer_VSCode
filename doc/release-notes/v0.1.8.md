# WPF XAML Live Preview v0.1.8 (미리보기 릴리스)

안정성/하드닝 릴리스입니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 수정
- **요소 형태의 사용자 마크업 확장**(`<TextBlock.Text><local:Loc Key="x"/></TextBlock.Text>`)이 있어도 그 속성 요소만 제거하고 나머지를 그립니다. 이로써 프로젝트 DLL을 불러오지 않은 모드에서 알려진 처리 한계가 모두 해소되었습니다.

## 개선 (이전 보안 점검에서 보류했던 낮은 위험 항목)
- 로그 파일 회전이 실패해도(다른 창의 호스트가 파일을 잡고 있는 경우) 로그를 잃지 않습니다.
- 요청 한 줄의 최대 길이(32M 문자)와 요청 큐(8줄)를 제한해 비정상적으로 큰 입력이 메모리를 채우지 못합니다.
- 임시 복사본에 `.pdb`와 인증서/키 파일(`.pfx`, `.p12`, `.pem`, `.key`, `.snk`)을 복사하지 않습니다.
- 주 DLL은 그대로이고 의존 DLL만 다시 빌드된 경우도 감지해 새 DLL을 씁니다.
- 큰 응답을 받을 때의 불필요한 이차 비용 제거, 제한 모드 설명 번역.

## 참고
- 사용자 컨트롤을 실제로 그리려면 프로젝트를 빌드하고 **프로젝트 코드 실행을 허용**해야 합니다(놓쳤다면 툴바의 새로고침을 누르세요).
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 서명되지 않은 `.vsix`와 같은 잡에서 만든 체크섬은 그대로입니다. 출처를 모르는 저장소는 신뢰하지 마세요.

## 설치
`wpf-xaml-live-preview-0.1.8.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.8.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.
