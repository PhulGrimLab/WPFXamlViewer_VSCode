# WPF XAML Live Preview v0.1.4 (미리보기 릴리스 · 보안 보강)

두 번째 보안 점검의 결과를 반영한 릴리스입니다. v0.1.3 사용자도 업데이트를 권장합니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 보안
- **신뢰하지 않은 폴더의 XAML 검사 보강**: 파일/네트워크 위치를 읽어 오는 값을 멤버 이름뿐 아니라 값의 **형식**과 `Setter.Value` 같은 일반 값 멤버에서도 막습니다(이전에는 `Setter Value="http://…"`, `Glyphs FontUri`, `Cursor="C:\…"`로 우회 가능).
- **프로젝트 코드 실행 경계를 워크스페이스로 통일**: 하위 폴더만 열었을 때 위쪽 폴더의 프로젝트 DLL이 로드되던 문제를 막았습니다. 확장과 호스트가 모두 열린 폴더 안의 `.csproj`/`.projitems`/산출물만 사용합니다.
- **프로젝트별 코드 실행 허용(새)**: 신뢰한 폴더라도 저장소에 커밋된 `bin/`의 DLL이 빌드 없이 실행될 수 있어, 프로젝트마다 처음 한 번 허용 여부를 묻습니다. 허용 전에는 DLL을 불러오거나 자동 빌드하지 않습니다. **이 변경으로 처음 미리보기할 때 허용 확인이 한 번 나타납니다.**
- 기타 하드닝(빌드 대기 제한 시간, `dotnet` 절대 경로, `.csproj` 선택 규칙 통일, 릴리스 워크플로, 문서 정정)은 CHANGELOG를 보세요.

## 설치
`wpf-xaml-live-preview-0.1.4.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.4.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.

## 알려진 한계
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 호스트는 일반 권한의 프로세스입니다. 출처를 모르는 저장소는 신뢰하지 마세요.
- 이번에 다루지 않은 낮은 위험 항목: 로그 파일 회전 실패 시 로그 유실과 창 간 로그 공유, 요청 큐/줄 길이 상한, 임시 복사본에 출력 폴더 전체를 복사, 의존 DLL만 바뀐 재빌드 미감지, 서명되지 않은 `.vsix`와 같은 잡에서 만든 체크섬.
- Visual Studio가 없는 깨끗한 PC에서의 설치/첫 실행, 미리보기 화면의 마우스 조작은 아직 사람이 확인하지 못했습니다.
