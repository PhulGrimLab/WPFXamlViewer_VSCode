# WPF XAML Live Preview v0.1.9 (미리보기 릴리스 · 사용성 개선)

사용성 평가를 반영한 릴리스입니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상). / English: see the [English README](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/blob/main/README.en.md) and [User Guide](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/blob/main/doc/User_Guide.en.md).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 개선
- **경고 목록이 미리보기 안에 보입니다.** 바꾸거나 제거한 내용이 있으면 위쪽에 "⚠ 경고 N개"가 나오고, 펼쳐서 항목을 누르면 해당 줄로 이동합니다.
- **프로젝트 코드 실행 허용 질문이 필요할 때만 나옵니다.** 사용자 타입 때문에 자리표시자가 쓰였거나 렌더가 실패했을 때만 묻고, 문구도 짧아졌습니다.
- **에디터 제목줄 아이콘**(미리보기 열기, 미리보기가 열려 있으면 새로고침)과 **누를 수 있는 상태 표시줄**(오류 → Problems 패널, 허용 대기/빌드 필요 → 새로고침).
- **접근성**: 툴바/버튼 `aria-label`, 상태 영역 `aria-live`, 지역화된 이미지 대체 텍스트.

## 문서
- **영문 README와 영문 사용자 가이드**를 추가했습니다. 확장 소개 페이지(README)는 영어 먼저 + 한국어 병기입니다.

## 참고
- 사용자 컨트롤을 실제로 그리려면 프로젝트를 빌드하고 **프로젝트 코드 실행을 허용**해야 합니다(놓쳤다면 툴바의 새로고침을 누르세요).
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 출처를 모르는 저장소는 신뢰하지 마세요.

## 설치
`wpf-xaml-live-preview-0.1.9.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.9.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.
