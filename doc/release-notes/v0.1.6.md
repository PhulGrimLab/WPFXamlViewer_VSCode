# WPF XAML Live Preview v0.1.6 (미리보기 릴리스)

수정 릴리스입니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 수정
- **프로젝트 DLL을 불러오지 않은 미리보기가 사용자 타입의 `{x:Static}`/첨부 속성 때문에 통째로 실패하던 문제**: `{x:Static local:InverseBool.Instance}`는 `{x:Null}`로 대체하고, `local:AutoScroll.Enabled="True"` 같은 프로젝트 타입의 첨부 속성은 그 속성만 제거한 채 나머지를 그립니다. 경고로 알립니다. 프로젝트 코드 실행을 허용하기 전이나 빌드 산출물이 없을 때의 미리보기에 해당합니다.
- 프로젝트 코드 실행 허용을 **지금은 안 함**으로 넘겼어도 **WPF XAML: Open Preview**를 다시 실행하면 다시 묻습니다.

## 참고
- 사용자 컨트롤을 실제로 그리려면 프로젝트를 빌드하고 **프로젝트 코드 실행을 허용**해야 합니다(처음 미리보기할 때 확인이 나타납니다).
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 출처를 모르는 저장소는 신뢰하지 마세요.

## 설치
`wpf-xaml-live-preview-0.1.6.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.6.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.
