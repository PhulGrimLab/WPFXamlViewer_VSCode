# WPF XAML Live Preview v0.1.1 (미리보기 릴리스)

v0.1.0의 수정 릴리스입니다. 설치 방법, 요구 사항, 보안/신뢰 안내는 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 신뢰한 폴더에서는 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 수정
- **자체 포함(`SelfContained=true`) 프로젝트에서 WPF UI 같은 라이브러리 컨트롤이 렌더되지 않던 문제**: 빌드 출력에 든 프레임워크 복사본(`PresentationFramework`, `System.Xaml`, `WindowsBase` 등)이 호스트의 WPF와 섞여 라이브러리의 `XmlnsDefinition`(`ui:FluentWindow`, `ui:SymbolIcon` 등)을 찾지 못했습니다. 이제 호스트가 가진 프레임워크 어셈블리를 씁니다. (실제 자체 포함 WPF UI 앱에서 뷰 13개 중 12개가 오류였던 것이 모두 렌더됨)

## 설치
`wpf-xaml-live-preview-0.1.1.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.1.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 0.1.0은 덮어써집니다.

## 아직 확인되지 않은 것
- Visual Studio가 없는 깨끗한 PC에서의 설치/첫 실행, 미리보기 화면의 마우스 조작은 아직 사람이 확인하지 못했습니다.
