# WPF XAML Live Preview v0.1.2 (미리보기 릴리스)

v0.1.1의 기능 추가 릴리스입니다. 설치 방법, 요구 사항, 보안/신뢰 안내는 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 신뢰한 폴더에서는 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 추가
- **한국어/영어 지원**: 상태 표시줄, 알림, 자동 빌드 안내, 미리보기 도구 모음, 호스트의 경고/오류 문구를 두 언어로 표시합니다. 기본(`wpfXamlViewer.language` = `auto`)은 VS Code 표시 언어(기본적으로 Windows 언어)를 따르고, 한국어가 아니면 영어입니다. 명령 **WPF XAML: 언어 전환 (한국어 / English)** 또는 설정으로 바꾸면 바로 적용됩니다. 메뉴/명령/설정 제목은 VS Code 표시 언어를 따릅니다. 로그와 .NET이 만드는 XAML 파싱 오류 원문은 번역하지 않습니다.
- **빌드 산출물이 없으면 미리보기가 프로젝트를 자동 빌드**: `bin`을 정리해 프로젝트가 빌드되어 있지 않으면 라이브러리 컨트롤(예: WPF UI)을 찾지 못해 "알 수 없는 형식" 오류가 났습니다. 이제 그 XAML이 속한 `.csproj`를 자동으로 빌드한 뒤 다시 그리고, 빌드에 실패하면 "이 XAML을 미리 보려면 프로젝트가 먼저 빌드되어야 하는데 실패했다"는 안내를 표시합니다(알림의 **다시 빌드**로 재시도). 신뢰된 폴더에서만 동작하며 설정 `wpfXamlViewer.autoBuildOnPreview`로 끌 수 있습니다.
- **우클릭 "구성 선택 빌드" 서브메뉴**: `.csproj`/`.sln`/`.slnx`/`.slnf`를 우클릭해 빌드 / 다시 빌드(`.csproj`만) / 정리를 Debug 또는 Release로 고릅니다.

## 설치
`wpf-xaml-live-preview-0.1.2.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.2.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.

## 아직 확인되지 않은 것
- Visual Studio가 없는 깨끗한 PC에서의 설치/첫 실행, 미리보기 화면의 마우스 조작, 언어 전환 시 실제 화면은 아직 사람이 확인하지 못했습니다.
