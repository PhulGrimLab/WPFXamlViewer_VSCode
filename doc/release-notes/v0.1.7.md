# WPF XAML Live Preview v0.1.7 (미리보기 릴리스)

미리보기 안정성 개선 릴리스입니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 추가
- **↻ 새로고침 버튼**(미리보기 툴바 맨 왼쪽)과 명령 **WPF XAML: 미리보기 새로고침**: 렌더가 실패했을 때 고친 뒤 다시 그립니다. 실패했던 자동 빌드와 프로젝트 코드 실행 허용 확인도 다시 시도합니다.

## 수정
- **프로젝트 코드를 아직 허용하지 않았거나 빌드 전이어도 미리보기가 훨씬 잘 그려집니다.** 만들 수 없는 프로젝트/라이브러리 타입을 참조하는 흔한 패턴(컨버터 리소스, `ItemTemplateSelector`, 사용자 마크업 확장 `{local:Loc …}`, 사용자 타입의 `{x:Static}`/첨부 속성, Blend 동작, 외부 라이브러리 컨트롤 등) 하나 때문에 전체가 실패하던 문제를 고쳐, 그 부분만 대체/제거하고 나머지를 그리며 경고로 알립니다. PathDock에서 신뢰하지 않은 모드로 그려지는 뷰가 13개 중 4개에서 13개로 늘었습니다.
- 자리표시자가 사용자 요소의 `MinWidth` 등과 겹쳐 XML 오류가 나던 문제.

## 참고
- 사용자 컨트롤을 실제로 그리려면 프로젝트를 빌드하고 **프로젝트 코드 실행을 허용**해야 합니다(처음 미리보기할 때 확인이 나타납니다. 놓쳤다면 새로고침을 누르세요).
- 아직 처리하지 않는 것: 요소 형태의 사용자 마크업 확장(`<TextBlock.Text><local:Loc Key="x"/></TextBlock.Text>`).
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 출처를 모르는 저장소는 신뢰하지 마세요.

## 설치
`wpf-xaml-live-preview-0.1.7.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.7.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.
