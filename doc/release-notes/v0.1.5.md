# WPF XAML Live Preview v0.1.5 (미리보기 릴리스 · 성능 개선)

성능 개선 릴리스입니다. 설치 방법, 요구 사항은 [v0.1.0 릴리스 노트](https://github.com/PhulGrimLab/WPFXamlViewer_VSCode/releases/tag/v0.1.0)와 같습니다(Windows 10/11 x64, .NET 10 Desktop Runtime, VS Code 1.90 이상).

> **이 버전은 시험 단계(Pre-release)입니다.** 코드 서명이 없고, 허용한 프로젝트의 빌드된 DLL을 불러와 사용자 코드를 실행합니다.

## 개선
- **첫 프로젝트 미리보기가 약 2배 빠릅니다.** 자체 포함(self-contained) 프로젝트의 프레임워크 DLL 복사를 건너뜁니다. 실측(PathDock): 첫 프로젝트 렌더 3.0초 → 1.35초, 임시 폴더 사용량과 디스크 쓰기도 크게 감소. 재빌드 뒤 다시 불러올 때도 같습니다.
- **편집 뒤 갱신이 빠릅니다.** 입력 뒤 대기 시간을 마지막 렌더 시간에 맞춰 100~300ms로 조절합니다(이전 고정 300ms). 가벼운 XAML은 약 200ms 빨리 갱신됩니다.
- 프로젝트 위치 조회 캐시, 미신뢰 가드 정규식 단순화.

## 알려진 한계
- 호스트가 처음 렌더할 때 WPF 초기화로 약 1.5초가 걸립니다(두 번째 렌더부터 수 ms). 호스트를 미리 띄우는 방식은 상주 메모리(약 70MB) 때문에 넣지 않았습니다.
- 신뢰하지 않은 폴더의 보호는 허용 목록 방식이지만 완전한 샌드박스는 아닙니다. 출처를 모르는 저장소는 신뢰하지 마세요.
- Visual Studio가 없는 깨끗한 PC에서의 설치/첫 실행, 미리보기 화면의 마우스 조작은 아직 사람이 확인하지 못했습니다.

## 설치
`wpf-xaml-live-preview-0.1.5.vsix`와 `SHA256SUMS.txt`를 내려받아 체크섬을 확인한 뒤 `code --install-extension .\wpf-xaml-live-preview-0.1.5.vsix`로 설치합니다. 이 확장은 자동 업데이트되지 않으므로 기존 버전은 덮어써집니다. VS Code가 실행 중이면 먼저 종료하세요.
